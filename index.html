🔹 1. Formules fondamentales ▶

Identités : $\cos^2 x + \sin^2 x = 1$, $\tan x = \frac{\sin x}{\cos x}$.

📌 Formules d'addition

$\cos(a+b) = \cos a \cos b - \sin a \sin b$
$\sin(a+b) = \sin a \cos b + \cos a \sin b$
$\cos(2a) = \cos^2 a - \sin^2 a = 2\cos^2 a - 1 = 1 - 2\sin^2 a$
$\sin(2a) = 2\sin a \cos a$

📐 Transformation produit-somme

$\cos p + \cos q = 2\cos\frac{p+q}{2}\cos\frac{p-q}{2}$
$\sin p + \sin q = 2\sin\frac{p+q}{2}\cos\frac{p-q}{2}$

🔹 2. Équations trigonométriques ▶

Équations de référence :

📌 Résolutions

$\cos x = \cos a \Leftrightarrow x = a + 2k\pi$ ou $x = -a + 2k\pi$ ($k\in\mathbb{Z}$).

$\sin x = \sin a \Leftrightarrow x = a + 2k\pi$ ou $x = \pi - a + 2k\pi$.

$\tan x = \tan a \Leftrightarrow x = a + k\pi$ ($x, a \neq \frac{\pi}{2} + k\pi$).

🔹 3. Fonctions réciproques $\arcsin$, $\arccos$, $\arctan$ ▶

Définitions :

📌 Domaine et image

$\arcsin x \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ pour $x\in[-1,1]$.
$\arccos x \in [0, \pi]$ pour $x\in[-1,1]$.
$\arctan x \in ]-\frac{\pi}{2}, \frac{\pi}{2}[$ pour $x\in\mathbb{R}$.

📐 Dérivées

$(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$
$(\arccos x)' = -\frac{1}{\sqrt{1-x^2}}$
$(\arctan x)' = \frac{1}{1+x^2}$

🔹 4. Euler & Moivre ▶

Formule d'Euler : $e^{i\theta} = \cos\theta + i\sin\theta$.

📌 Conséquences

$\cos\theta = \frac{e^{i\theta}+e^{-i\theta}}{2}$, $\sin\theta = \frac{e^{i\theta}-e^{-i\theta}}{2i}$.

Formule de Moivre : $(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)$.

Utile pour linéariser $\cos^n\theta$ et $\sin^n\theta$, ou exprimer $\cos(n\theta)$ en fonction de $\cos\theta$.
